## Что от нас хотят

**Трек 3 · Цифровая экосистема МТК «Север–Юг».**
МТК «Север–Юг» — артерия Россия–Иран–Индия–Центральная Азия.
Каспийское море — критический узел: порты Астрахани, Махачкалы,
Энзели, Амирабада.

**Главная боль (дословно из кейса):** рассинхронизация между ж/д,
авто и морским транспортом, простои на таможне и непредсказуемость
погоды на море → срыв графиков.

**Задача:** концепция и прототип цифровой экосистемы (платформы),
которая обеспечивает бесшовное отслеживание груза и предсказывает
узкие места в каспийском звене МТК **до их возникновения**.

## Требования к результату (MVP) — все три закрыты прототипом

| № | Требование кейса | Где в прототипе |
|---|---|---|
| 1 | **Предиктивная модель:** прогноз задержек мультимодальных перевозок по историческим данным, погоде на Каспии и загруженности портов (стыковка ж/д и парома) | `backend/app/model.py` — объяснимый скоринг: волна/ветер, загруженность порта, очередь на таможне, пропуск парома. `GET /api/routes/{id}/forecast`, `GET /api/compare` |
| 2 | **Смарт-контракт / Цифровой коридор:** прототип автоматического таможенного оформления (pre-clearance) на распределённом реестре или защищённых API | `POST /api/clearance/submit` + `GET /api/clearance/ledger`: проверка документов до прибытия, решение пишется в append-only реестр с hash-связкой (упрощённая модель DLT) |
| 3 | **Единое окно логиста:** цифровой двойник груза с расчётом углеродного следа (ESG) и альтернативными маршрутами при форс-мажоре | Главная страница: карта коридора, двойник груза (таймлайн плеч), CO₂ на маршрут, таблица 3 маршрутов, кнопка «Шторм на Каспии» пересчитывает всё |

**Стек из кейса:** Predictive Analytics · Graph Databases · API-интеграции ·
Blockchain / Smart Contracts (опционально) · Digital Twin.
Наш стек: Python + FastAPI, объяснимый скоринг вместо «чёрного ящика»,
hash-chain реестр вместо полноценного блокчейна (честно подписано),
граф маршрутов — как структура данных (узлы/рёбра) с API.

## Честные ограничения (говорим на защите первыми)

- **В файле кейсов нет критериев оценки, сроков и формата защиты.**
  Их надо уточнить у организаторов утром — в `docs/PLAN.md` это первый пункт.
- **ML-слой дообучен на реальных распределениях погоды**
  (`backend/app/ml.py` + `archive_weather.json`): RandomForest,
  волна/ветер — bootstrap из 90-дневного архива Open-Meteo,
  MAE 1,97 ч, R² 0,894. Метки задержек — по-прежнему правила
  коридора + шум: публичного датасета реальных задержек нет.
  Замена генератора на реальный CSV — одна функция.
- Реестр pre-clearance — **упрощённая hash-chain модель** в памяти, а не
  production-блокчейн. Механика (связка хешей, проверка целостности)
  показана настоящая.
- Загруженность портов и очереди на таможне — **демо-снимок**,
  живого открытого фида для них нет. Замена — один файл
  `backend/app/data.py`.

## Почему старый прототип удалён

Первый прототип («Двойник Каспия», коммит `35b85d0d`) был про уровень
моря и экологию — это тема кейса №1, а не №2. По приказу Курбана он
полностью удалён из репозитория (коммит ниже заменяет дерево целиком),
сохранены только приёмы каркаса: FastAPI + статический фронт + Docker +
тесты + `run.sh`.
