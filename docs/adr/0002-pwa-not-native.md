# ADR-0002: PWA, а не native Android/iOS

Дата: 2026-11-12 · Статус: принято · Цикл 7

## Контекст
Кейс требует «единое окно логиста» с телефона и демо на сцене. Проверяемые
задачи: просмотр груза/риска/альтернатив, сценарии, pre-clearance, события.
Offline-документы, push, камера, геолокация, подпись, background sync в MVP
не требуются (документы — ссылки, не файлы; трекинг — не GPS).

## Варианты
1. **PWA (статика + service worker)** — один код, мгновенный деплой, установка
   на домашний экран, offline-оболочка; проверяемо в браузере жюри.
2. **Native (Kotlin/Swift или Flutter)** — даёт push/камеру/background, но
   ×2–3 время, отдельные сборки, сторы/подписи; для 2-дневного хакатона и
   демо-сценария выигрыша нет.

## Решение
PWA. Проверено: manifest с иконками 192/512 (installable), SW v2 network-first
для навигации (не stale), offline-баннер и кэш-оболочка (тест Playwright:
offline reload → оболочка + баннер, online → восстановление), mobile 390×844:
overflow 0, touch targets ≥ 44px, полный сценарий создания/шторма/clearance.

## Последствия
+ Демо с любого телефона без установки из стора.
− Нет push/фоновой синхронизации; при появлении требования offline-документов
  с подписью — пересмотреть (гибрид допустим). Тайлы OSM требуют сети.
