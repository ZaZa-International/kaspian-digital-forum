# ML Data Contract — реальные истории задержек

Статус: **контракт готов, реальных данных нет**. Открытого исторического
датасета фактических задержек каспийских паромов/портов не найдено
(docs/RESEARCH.md, 12.11.2026). Пока модель обучается на синтетическом
генераторе (правила коридора + шум; волна/ветер — bootstrap из реального
архива Open-Meteo). Все метрики в этом режиме — **synthetic benchmark**,
не точность прогноза реальных рейсов.

## Как подключить реальные данные

1. Соберите CSV с фактическими завершёнными перевозками (колонки ниже).
2. Запустите backend с `SCT_ML_HISTORY_CSV=/path/to/history.csv`.
3. `/api/ml/info` покажет `dataset.kind = csv`, hash, split и метрики.
   Прежде чем заявлять точность на реальных рейсах, проверьте provenance
   каждой строки (источник, лицензия, полнота).

## Колонки CSV

| Колонка | Тип | Единицы | Обязательна | Описание |
|---|---|---|---|---|
| max_wave_m | float | м | да | макс. значимая волна на морских плечах за рейс |
| max_wind_ms | float | м/с | да | макс. ветер на морских плечах |
| max_congestion_pct | int | % (0–100) | да | макс. загруженность порта на маршруте |
| total_customs_h | float | ч | да | суммарная таможенная очередь по плечам |
| sea_km | float | км | да | суммарная длина морских плеч |
| rail_km | float | км | да | суммарная длина ж/д плеч |
| weight_t | float | т | да | вес груза |
| sea_legs | int | шт | да | число морских плеч |
| delay_h | float | ч, ≥ 0 | да | **фактическая** задержка против плана (label) |
| departed_at | ISO 8601 | UTC | нет | время отправления; при наличии — хронологический split 80/20 |

Требования: числовые поля без пропусков; delay_h ≥ 0; одна строка = одна
завершённая перевозка (не повторяйте один груз в train и test — group
leakage). При наличии departed_at используется хронологический split
(walk-forward рекомендуется для production). Шаблон:
`scripts/ml_history_template.csv` (строки — синтетический пример).

## Сбор фактических событий (альтернативный путь)

- `POST /api/shipments/{id}/events` — фактические события (тип, время,
  источник, место, уверенность). received_ts ставит сервер.
- Адаптеры снапшотов (docs/RESEARCH.md §6): ships.asco.az, portkuryk.kz —
  без открытой лицензии и архива; парсить hourly, хранить сырые снапшоты,
  дедуплицировать по (vessel, event_type, ts), delay = факт − последний
  опубликованный ETA. Схема: ferry_event / port_call / weather_hourly.
- Погода: Open-Meteo archive API (CC BY 4.0, атрибуция обязательна;
  free tier — non-commercial).

## Воспроизводимость

Фиксируются: seed (42), версии scikit-learn/numpy, hash датасета
(SHA-256 от X,y), split, метрики всех моделей (RF, HGB, ансамбль, LR
baseline) — `/api/ml/info`. Повторное обучение на тех же данных даёт
идентичные метрики (тест test_ml.py).
