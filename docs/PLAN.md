время защиты уточнить у организаторов** (в файле кейсов нет ни

## День 1 — 13 ноября: продукт готов к защите

### 08:00–09:00 — Сверка с организаторами (самое важное)

- [ ] Уточнить **дату/время защиты, критерии оценки, регламент и формат** —

- [ ] Уточнить, есть ли исторические данные / API погоды / портов.
- [ ] Подтвердить состав команды и кто защищает.

### 09:00–11:00 — Данные и модель

- [ ] Проверить живую погоду: открыть `/api/weather/live` — должен
      быть `live: Open-Meteo`. Если на площадке нет интернета —
      демо-фолбэк работает сам, ничего не чинить.
- [ ] Если дали реальные данные (история рейсов, загруженность) —
      заменить демо-снимок в `backend/app/data.py`; историю рейсов
      подключить через `SCT_ML_HISTORY_CSV` (docs/ML_DATA_CONTRACT.md),
      погоду обновить `python3 scripts/fetch_weather_archive.py`.
- [ ] Прогнать `cd backend && python -m pytest -q` (82 теста), проверить `/docs`.
- [ ] Сбросить демо-состояние: `POST /api/demo/reset`.

### 11:00–14:00 — Фронт и демо

- [x] Главный экран: карта + сравнение + калькулятор + двойник груза +
      pre-clearance + порты + события + provenance. Ничего лишнего не добавлять.
- [x] Мобильная вёрстка: KPI по 2 в ряд, без горизонтального скролла,
      touch targets 44px; быстрая навигация в шапке.
- [x] Локальный Leaflet (вендорен в `static/vendor/`) — CDN не нужен;
      тайлы OSM — по сети, офлайн карта без тайлов.
- [x] PWA: sw.js v2, manifest, иконки, офлайн-баннер.
- [ ] Скриншоты карты и таблицы — запасной вариант без интернета.
- [ ] Проверить офлайн-режим вживую (авиарежим): оболочка из кэша,
      баннер, демо-фолбэк погоды.

### 14:00–17:00 — Защита (репетиция)

- [ ] Репетиция питча по `docs/PITCH.md` — **ровно 3 минуты**, с таймером,
      минимум 3 прогона. Главные клики: кнопка шторма, сценарий
      волна/ветер, поиск + закрытие Махачкалы (маршрут на карте),

- [ ] Прогнать `docs/DEMO_RUNBOOK.md` целиком (3–5 мин), знать, что
      резать до 3 минут.
- [ ] Подготовить ответы на вопросы из `PITCH.md`.
- [ ] Проверить запуск с нуля на чистом ноутбуке: `git pull` →
      `./run.sh` (Python 3.12) → открыть страницу. Если дольше 2 минут — чинить.
- [ ] Залить финальный коммит дня, проверить свежую версию на GitHub.

## Если что-то пошло не так

| Проблема | Действие |
|---|---|
| Дали реальные данные поздно | Меняем только `data.py` / CSV для ML, фронт и API не трогаем |
| Нет интернета на площадке | Локальный запуск + скриншоты; Leaflet локально; PWA-оболочка из кэша; погода — демо-фолбэк |
| Падает бэкенд | `docker compose up` как план Б (volume sct-data сохраняет состояние); фронт показывает ошибку честно |
| Испортили демо-состояние | `POST /api/demo/reset` — секунда, seed-грузы остаются |
| Не хватает времени | Режем события/provenance из демо, оставляем карту + прогноз + шторм + pre-clearance |
