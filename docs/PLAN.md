блок, Курбан — капитан и питч.

- [ ] Уточнить **критерии оценки, регламент и формат защиты** —
      в файле кейсов их нет (ни баллов, ни времени питча, ни дедлайна сдачи).

      если дадут файл, парсить его в `data.py` вместо демо-снимка.

## 09:00–11:00 — Данные и модель

- [ ] Если дали реальные данные — заменить демо-снимок в
      `backend/app/data.py` (погода, загруженность, очереди).

      шторм должен ронять морские маршруты и не трогать сухопутный
      (это покрыто тестом `test_storm_makes_sea_routes_worse`).
- [ ] Прогнать `pytest -q`, проверить `/docs`.

## 11:00–14:00 — Фронт и демо

- [ ] Главный экран: карта + сравнение + двойник груза + pre-clearance.
      Ничего лишнего не добавлять.

- [ ] Скриншоты карты и таблицы — запасной вариант без интернета.

## 14:00–16:00 — Защита

- [ ] Подготовить ответы на 5 вопросов из `PITCH.md`.
- [ ] Проверить запуск с нуля на чистом ноутбуке: `git pull` →

- [ ] Залить финальный коммит, проверить свежую версию на GitHub.

## 16:00 — Защита

- [ ] Один человек говорит, второй — за клавиатурой (шторм,
      pre-clearance), третий — страхует запасными скриншотами.
- [ ] После защиты: записать вопросы жюри — пригодятся для доработки.

## Если что-то пошло не так

| Проблема | Действие |
|---|---|
| Дали реальные данные поздно | Меняем только `data.py`, фронт и API не трогаем |
| Нет интернета на площадке | Локальный запуск + скриншоты; Leaflet локально |
| Падает бэкенд | `docker compose up` как план Б; фронт показывает ошибку честно |
| Не хватает времени | Режем реестр до одной кнопки, оставляем карту + прогноз + шторм |
