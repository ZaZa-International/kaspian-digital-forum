# Проверка ML-версии — 13 ноября 2026

## Поведение

- **PASS:** 19 существующих браузерных сценариев — карта WebGL/SVG,
  погода, выбор и сохранение маршрута, экономика, документы TXT/PDF/OCR,
  события, демонстрация, мобильные размеры, уменьшенное движение и офлайн.
- **PASS:** 7 новых браузерных сценариев — ML-интервал и объяснение,
  сценарий без записи плана, отмена устаревшего запроса, ошибка/повтор,
  явное сохранение прогноза, исключение демо, фактическое прибытие и CSV,
  мобильная вёрстка и клавиатура. Часть сценариев объединяет несколько
  связанных проверок.
- **PASS:** API и ML-тесты, включая независимые выборки, временное
  разделение и доступность меток, проверку CSV, диапазоны и OOD,
  воспроизводимость, оставшийся маршрут, единую версию модели на ответ,
  идемпотентность и сопоставление с фактическими событиями.
  Полный прогон дал 138 пройденных и четыре ошибки в устаревших тестовых
  заглушках. После обновления сигнатур все 11 тестов журнала и интеграции
  прошли. Проверки внешнего EVM-якоря пропущены: зависимость не подключена.
- **PASS:** после перезапуска локального сервера health, прогноз и журнал
  отвечают HTTP 200. Рабочая база сохранена; тесты выполнялись отдельно.

Команды: `python -m pytest backend/tests -q`, `PW_CHANNEL=chrome npm run
test:ui`, `PW_CHANNEL=chrome npm run test:ml-ui`. Для точечных проверок:
`python -m pytest backend/tests/test_ml_journal.py
backend/tests/test_operations_intelligence.py -q`.

## Оценка модели

[Машиночитаемый отчёт](ml-evaluation.json) создан локальной командой
`python scripts/evaluate_ml.py`. На одинаковом отложенном наборе из 120
синтетических примеров выбранный на валидации RandomForest имеет MAE
3,683 ч против 5,597 ч у линейной регрессии и 11,484 ч у медианы.
Номинальный интервал 90% покрывает 110 из 120 целей, средняя ширина
15,085 ч. Эти числа не сравниваются с прежними метриками на другом
генераторе и другом разбиении.

**NOT_TESTED:** реальная точность и покрытие на эксплуатационной истории,
приёмка таможней, внешнее блокчейн-якорение, производственная нагрузка.
Результат — локально проверенный прототип.
