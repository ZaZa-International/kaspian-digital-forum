## 3. Метрики продукта (определения и источники)

- **База маршрутов (ход)**: R1 122 ч, R2 108 ч, R3 94 ч — сумма base_h плеч
  (data.py; оценки, не тарифные расписания). Время в пути = ход + ожидание
  парома (36 ч/морское плечо, допущение interval/2) + задержки.
- **Индекс риска** = delay/(delay+18), пол 0.85 для моря в шторм — эвристика,
  НЕ эмпирическая вероятность (model.py, подписано в API/UI).
- **P50/P90/P95** — квантили Monte Carlo (200 прогонов, seed 7): волна/ветер —
  bootstrap реального архива Open-Meteo (90 дней, 364 точки/сегмент),
  загруженность ~N(демо,8), таможня ~N(демо,30%), ожидание ~U(0,72).
  НЕ гарантия фактической доставки.
- **ML (synthetic benchmark, holdout 160 из 800, seed 42)**: RF MAE 1.97 ч /
  R² 0.894; HGB 2.32/0.826; ансамбль 2.07/0.877; LR 2.45/0.818. Качество
  воспроизведения синтетического генератора, НЕ точность реальных рейсов.
- **CO₂e**: DESNZ 2026 flat v1.2, WTW, г/т-км: rail 25.83, RoRo 51.58,
  HGV 122.92 (строки файла в data.CO2_FACTOR_META). UK proxy, indicative;
  тотал = round(Σ неокруглённых плеч × вес); хабы/перегрузки не учтены.
- **Стоимость**: оценка $/т-км (0.04/0.045/0.12), порядок величины Argus
  Oct 2025; точная калибровка не выполнена.

## 4. Ограничения и блокеры (честно)

1. **Нет реальных исторических задержек** (RESEARCH.md §6): открытого
   датасета нет; порты/Росморречфлот/АСОП недоступны (403/нет соединения);
   AIS платный/закрытый. ML — эксперимент; путь к данным готов (CSV-контракт,
   события, схема снапшот-адаптеров ASCO/Курык).
2. **Линии Махачкала–Амирабад/Энзели не подтверждены** как регулярные —
   плечи условные (маркированы). Актау–Бендер-Аббас (KTI) — абстрактное плечо.
3. **CO₂ — UK proxy без верификации**; заявление «ISO 14083 compliant»
   не делается (только «согласовано с методологией»).
4. **Pre-clearance — симуляция органа**, не юридическое решение; hash-chain —
   tamper-evident демо, не DLT; компрометация процесса = подмена цепочки.
5. **События — не GPS/AIS**: демо-симуляция + ручной ввод; live-трекинг не заявлен.
6. **Один процесс + SQLite**: для пилота с несколькими writers нужен внешний
   storage, RBAC, подписи (ROADMAP).
7. **run.sh требует Python 3.12** (на хосте 3.15 — не собирается; Docker работает).
8. **Open-Meteo free tier — non-commercial**; для коммерции нужна подписка.
9. **Карта — схема** (прямые сегменты), тайлы OSM требуют сети.
10. Deprecation warning anyio в testclient — косметический, объяснён выше.
11. Визуальная проверка скриншотов недоступна в этой сессии (модель без
    image-input) — UI проверен через DOM/accessibility/network в Playwright.

## 5. Backlog (приоритеты после хакатона)

1. Снапшот-адаптеры ships.asco.az / portkuryk.kz (hourly, сырые снапшоты,
   дедуп, delay = факт − опубликованный ETA) → реальные метки для ML.
2. Хронологический walk-forward ML на реальных данных; калибровка квантилей
   (coverage/quantile loss), дрейф.
3. Berth/ETA-ETB синхронизация (паттерн Portchain/PortXchange): окно швартовки
   как «рукопожатие» порта и парома; missed-connection penalty по расписанию.
4. Production pre-clearance: электронные подписи, RBAC, интеграция с
   таможней/единым окном (UN/CEFACT MMT, DCSA eBL-паттерн), внешний реестр/DLT.
5. Реальные тарифные километражи и расписания; локальные CO₂-факторы
   (энергобаланс РФ/Иран/КЗ), верификация отчёта по ISO 14083.
6. Уведомления (push/email), multi-writer storage, аудит-лог, rate limiting
   на reverse-proxy, HTTPS.
7. Глобальный multi-objective Pareto (вместо эвристики среди k кандидатов).
