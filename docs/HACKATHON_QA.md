# Проверки расширения MVP — 13 ноября 2026

Проверялась локальная версия на ветке `coneldiablo/caspian-command-center`.
Backend: Python 3.13 в `.venv`. Браузер: установленный Google Chrome через
Playwright. Все автоматические записи выполнялись в отдельных временных
базах; рабочая база пользователя не сбрасывалась.

Полный pytest прошёл за 59,24 с. Получено предупреждение об устаревающем
алиасе `BlockingPortal` внутри установленного Starlette TestClient;
падений тестов нет. Отдельные проверки цифрового коридора включают
повтор запроса, гонку выпуска, изменённую версию плана, иной комплект
документов, подставленный ключ и JSON с повторяющимися ключами.

## Визуальная проверка

Проверены скриншоты панелей в viewport 1440×920 и 390×844. Для снимков
включён reduced motion. Независимый ревьюер применил Oil UI к расширению
существующего интерфейса без выставления числовой оценки. По его замечаниям
улучшены мобильное сравнение маршрутов, положение статусов документов,
цвета рабочих состояний и расположение подробной методики. Повторное
независимое ревью обновлённых четырёх снимков подтвердило устранение
перечисленных проблем.

Снимки и результаты локальных браузерных проверок лежат в `artifacts/qa/`:
`resilience-desktop.png`, `resilience-mobile.png`, `corridor-desktop.png`,
`corridor-mobile.png`. Скриншоты — захваты самих панелей; они не заменяют
измерение производительности 3D на физическом телефоне.

## Границы результата

- **NOT_TESTED:** реальные портовые/таможенные интеграции, внешние
  перевозчики, подтверждённые рейсы и точность на реальных исходах.
- **NOT_TESTED:** промышленное развёртывание, нагрузка нескольких
  организаций, независимый аудит защиты и FPS на физических телефонах.
- **NOT_TESTED:** внешний блокчейн. Основной сценарий работает с локальной
  подписью Ed25519 и защищаемым API, без EVM.
- Доли пропусков, P50/P90, стоимость и эффект сокращения очереди относятся
  к заданной симуляции. Совпадение полей не подтверждает подлинность
  документа или таможенный выпуск.
