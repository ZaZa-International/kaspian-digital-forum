# API рабочей области

`GET /api/workspace` собирает перевозки, документы, задачи и недавние события в одной читающей транзакции SQLite. Параметры `storm`, `close`, `extra_customs_h`, `wave_m`, `wind_ms` совпадают с API пульта. Ответ помечается `Cache-Control: no-store`. Значения `eta`, `remaining_h`, `remaining_cost_usd`, `remaining_co2_kg` и `financial_risk_usd` остаются `null`, когда расчёт закрыт условиями сценария.

| Поле | Содержимое |
|---|---|
| `generated_at`, `scenario` | Время снимка UTC и условия расчёта |
| `summary` | Число перевозок, активных и доставленных, расчётных опозданий, рисков, блокировок, активных перевозок с документами, требующими внимания, задач и сигналов. Отдельно суммы расчётной стоимости, финансового риска и CO₂e |
| `shipments` | Данные груза, `demo`, принятый маршрут, `plan_version`, текущее положение, срок, ETA, документальный статус и экономика остатка пути |
| `alerts` | Расчётные сигналы по принятому маршруту, сроку и комплекту документов с `kind`, `severity`, причиной, рекомендуемым действием и `target` для перехода в пульт или документы |
| `documents` | Статусы требований, число расхождений, идентификаторы и основные метаданные загруженных файлов. Оригиналы и извлечённые значения остаются вне сводки |
| `tasks` | Задачи оператора, включая закрытые. Открытые идут выше закрытых, далее учитывается приоритет и срок |
| `activity` | До 20 последних действий по времени записи. Включает события перевозки, создание перевозки, загрузку файла и последнее состояние каждой задачи |
| `analytics` | Группы по статусу, риску и исходному шаблону маршрута. Суммы по принятому остаточному пути в USD и кг CO₂e, число перевозок с доступным расчётом и без него |

Риск `critical` означает блокировку пути или расчётное опоздание. `elevated` означает запас до срока менее 24 часов, зарегистрированную задержку или расчётное ограничение по волне на оставшемся морском плече. `normal` означает, что эти признаки не обнаружены. Доставленный груз получает `complete` и исключается из активной очереди рисков. Поле `risk_reason` указывает правило. Сигналы документов рассчитываются отдельно по требованиям паспорта. `documents_blocked_count` включает активные перевозки со статусом `missing`, `mismatch` или `review_required`. Выполнение задачи само по себе не меняет документы, маршрут и риск.

Время, расходы и CO₂e получены из модели пульта. Эти суммы включают демонстрационные грузы, помеченные `demo: true`. Доставленные перевозки и активные перевозки без доступного расчёта исключаются из сумм. Нулевой итог при отсутствии доступных расчётов читается вместе с `projected_shipments_count`. Группа `by_route` использует исходный шаблон, а числа внутри группы учитывают актуальную версию плана. Финансовый риск соответствует оценке простоя и опоздания из пульта. Загрузка рабочей области не запускает ML-обучение.

## Запись задач

`POST /api/workspace/tasks` создаёт задачу по `shipment_id` существующей перевозки. Требуется `Idempotency-Key` до 100 символов. Повтор с тем же нормализованным содержимым возвращает текущую версию той же задачи. Другое содержимое с тем же ключом возвращает 409. Если включён `SCT_WRITE_TOKEN`, запросы записи требуют `X-Write-Token`.

```json
{
  "shipment_id": "SHP-1042",
  "title": "Сверить накладную",
  "owner": "Ирина",
  "due_at": "2026-11-14T15:00:00+03:00",
  "priority": "high",
  "status": "open",
  "note": "Сверить массу с упаковочным листом"
}
```

`title` обязателен, от 1 до 140 символов. `owner` до 80 символов, `note` до 1000, оба могут быть пустыми строками. `due_at` принимает ISO 8601 со смещением или `null`, время сохраняется в UTC. `priority` принимает `normal`, `high`, `critical`, значение по умолчанию `normal`. `status` принимает `open`, `in_progress`, `done`, значение по умолчанию `open`. Ответ 201 содержит задачу, имя перевозки, `id`, `version`, `created_at` и `updated_at`.

`PATCH /api/workspace/tasks/{id}` принимает `expected_version` и любое непустое подмножество полей `title`, `owner`, `due_at`, `priority`, `status`, `note`. Переход в `done` закрывает задачу, переход обратно в `open` или `in_progress` открывает её. Неизменившиеся значения не увеличивают версию. Устаревшая версия возвращает 409. Попытка изменить неизвестную задачу или привязаться к неизвестной перевозке возвращает 404. Ошибки формы возвращают 422. Удаление пользовательской перевозки удаляет связанные задачи, сброс демо очищает все задачи, включая задачи по демонстрационным грузам.
