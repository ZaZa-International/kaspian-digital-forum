# Источники данных — Smart Caspian Transit

Каждый источник помечен типом (те же kind, что в `GET /api/provenance` —
11 источников): **live** (живой API), **historical** (исторический архив),
**static** (опубликованный справочник/коэффициент), **demo**
(иллюстративный снимок), **synthetic** (сгенерировано), **assumption**
(допущение/оценка). При недоступности live — **fallback** (демо-снимок).
Полная верификация источников — `docs/RESEARCH.md` (12.11.2026).

## Погода (live + historical)

| Источник | Тип | Что | Обновление |
|---|---|---|---|
| Open-Meteo Marine API (`wave_height`) | live | Волна на двух морских плечах | кэш 30 мин, фолбэк — demo |
| Open-Meteo Forecast API (`wind_speed_10m`) | live | Ветер на тех же точках | кэш 30 мин |
| Open-Meteo, архив 90 дней (14.08–11.11.2026) | historical | Распределения волны/ветра для ML и Monte Carlo | файл `archive_weather.json`, скрипт `scripts/fetch_weather_archive.py` |

**Лицензия: CC BY 4.0** — атрибуция обязательна («Weather data by
Open-Meteo.com», в UI и provenance). Free tier — **только
non-commercial** (<10 000 вызовов/день); для коммерческого продукта
нужна подписка.

Архив **прорежен**: в файле хранится каждый 6-й час (364 точки на
сегмент; у ветра западного сегмента 264 — пропуски/null исключены).
**Статистики в метаданных (mean/p50/p90/max/проценты) посчитаны по
полному архиву** (2184 ч на сегмент), не по прореженным сэмплам.

Проверено 12.11.2026: север — волна средняя 0,45 м, макс 1,24;
запад — средняя 0,71 м, p90 1,44, макс 2,52; волна ≥ 2 м — 2,3%
часов на западе, 0% на севере.

## География и расстояния (assumption)

Haversine по координатам узлов ×1,1 (морские плечи); ж/д/авто — оценки.
Махачкала–Амирабад — 844 км по прямой, Астрахань–Актау — 387 км.
Это **не фактические тарифные километражи**. Координаты портов — из
открытых географических данных. Актау в графе — паромный терминал
**Курык** (порт Актау не принимает паромы с 2018, Caravanistan 06.2026).

## Коридор (static, публичные данные)

21,5 млн т в 2025; янв–сен 2026 — 8,9 млн т ж/д (+9,6%),
транскаспийский +19,3%; прогноз 32 млн т к 2030; доставка 15–20
дней вместо 35–45 через Суэц. Порт Махачкала: 3,5 млн т в 2025,
янв–авг 2026 — 2,9 млн т (+42,5%), мощность ~10–11 млн т к 2030.
Источники: Правительство РФ / РЖД / Росморречфлот через прессу
(окт 2026); первичные сайты недоступны (403) — верифицировано через СМИ.

## Паромы (assumption + static)

Фиксированного расписания у каспийских паромов нет: рейс
Баку–Туркменбаши ~17 ч, Курык–Баку <24 ч, ожидание 1–2 дня —
норма, до недели при заторах (Caravanistan 06.2026, Wikivoyage,
снапшот ships.asco.az 12.11.2026). В модели: средний интервал
отправления 72 ч, **ожидание = interval/2 = 36 ч на морское плечо
(допущение)**, пропуск рейса при волне ≥ 2 м — **+48 ч**.
Monte Carlo сэмплирует ожидание из Uniform(0, 72).

**Условные плечи** (`conditional=true`, assumption): Махачкала–Амирабад
и Махачкала–Энзели — регулярные линии не подтверждены (тестовый рейс
2020, анонсы 2026); Актау–Бендер-Аббас — ж/д KTI, маршрут абстрактный,
километраж не верифицирован. См. RESEARCH.md §7.

## CO₂ (static — проверенные факторы) и стоимость (assumption)

**CO₂ — DESNZ 2026 GHG conversion factors, flat file v1.2 (31.07.2026),
well-to-wheel, г CO₂e/т-км** (лист «Freighting goods», Scope 3,
total CO₂e, GWP AR5):

| Вид | Фактор | Строка flat-файла |
|---|---|---|
| Ж/д (Freight train) | **25,83** | 27_315_3151_14_1 |
| Паром (RoRo-Ferry Average) | **51,58** | 27_320_3239_14_1 |
| Авто (articulated HGV, average laden) | **122,92** | 27_304_3128_14_1 |

Ранее использовавшиеся 32,74/63,28/97,49 **не найдены ни в одном издании
DESNZ 2023–2026 и удалены** (RESEARCH.md §1). Формулировка: «оценка по
методологии, согласованной с **ISO 14083 / GLEC v3.3, без верификации**».
География: **UK proxy** (UK парк/энергобаланс; морские — международные
средние IMO 2009) — **indicative для РФ/Иран/КЗ**, не локально
валидированные факторы. Не учтены: терминальные операции, перегрузка,
холостые пробеги. Единицы итогов — **kg CO₂e**; поля плеч
`co2_kg_per_t` / `cost_usd_per_t` — на тонну, тоталы умножаются на вес.
Разбивка по плечам (TCE) с методом и качеством данных — в ответе API.

**Ставки $/т-км — оценка** (ж/д 0,04 · море 0,045 · авто 0,12): порядок
величины согласуется с Argus Caspian Transport (окт 2025: Актау–иранские
порты $40–45/т, Астрахань–иранские $63–65/т). Точная калибровка по парам
портов **не выполнена**.

## Демо (demo — иллюстративный снимок, не live)

- Загруженность портов (%), очереди на таможне (ч) — `data.PORTS`.
- Список грузов SHP-1042/1043/1044, их документы и ETA.
- Фактические события seed-грузов — маркированы `demo-simulation`
  (не GPS/AIS/телематрия); новые события — ручной ввод или адаптер
  (`POST /api/shipments/{id}/events`, `source` обязателен).
- Сценарий шторма (ветер 19 м/с, волна 3,4 м — экстремум: за 90 дней
  максимум волны 2,52 м).

## Синтетика (synthetic)

- Метки задержек для ML: правила коридора + гауссов шум N(0; 2,5)
  (`ml.py`); волна/ветер при этом — bootstrap из реального архива.
  Метрики — synthetic benchmark, не точность на реальных рейсах.
  Реальные данные: CSV-контракт `SCT_ML_HISTORY_CSV`
  (`docs/ML_DATA_CONTRACT.md`).
- Загруженность/таможня в Monte Carlo — нормальные распределения
  вокруг демо-снимка.

## Что отсутствует (нет открытого источника)

- Живые данные портов (загруженность, расписание паромов). Есть
  операционные снапшоты **ships.asco.az** и **portkuryk.kz** — без
  открытой лицензии и без архива; для пилота — собственный сбор
  (hourly-снапшоты, дедупликация, сырые снапшоты; схема — RESEARCH.md §6).
- История реальных задержек рейсов (поэтому ML-метки синтетические).
- GPS/AIS-трекинг судов и вагонов (AISHub требует свой приёмник,
  MarineTraffic/Kpler — платно).
- API таможни для pre-clearance (статусы документов симулируются
  сервером, правила `demo-rules-v1`).

Для пилота эти данные берутся у порта и таможни напрямую —
см. ROADMAP.md.
