# Источники данных — Smart Caspian Transit

Каждый источник помечен типом: **live** (живой API), **archive**
(исторический архив), **default** (опубликованный коэффициент),
**demo** (иллюстративный снимок), **computed** (вычислено из других).

## Погода (live + archive)

| Источник | Тип | Что | Обновление |
|---|---|---|---|
| Open-Meteo Marine API (`wave_height`) | live | Волна на двух морских плечах | кэш 30 мин, фолбэк — demo |
| Open-Meteo Forecast API (`wind_speed_10m`) | live | Ветер на тех же точках | кэш 30 мин |
| Open-Meteo Marine, 90 дней (14.08–11.11.2026) | archive | Распределения волны/ветра для ML и Monte Carlo | файл `archive_weather.json`, скрипт `scripts/fetch_weather_archive.py` |

Проверено 12.11.2026: север — волна средняя 0,45 м, макс 1,24;
запад — средняя 0,71 м, p90 1,44, макс 2,52; волна ≥ 2 м — 2,3%
часов на западе, 0% на севере.

## География и расстояния (computed)

Haversine по координатам узлов × 1,1–1,15 (морские плечи).
Махачкала–Амирабад — 844 км, Астрахань–Актау — 387 км.
Координаты портов — из открытых географических данных.

## Коридор (default, публичные данные)

21,5 млн т в 2025; янв–сен 2026 — 8,9 млн т ж/д (+9,6%),
транскаспийский +19,3%; прогноз 32 млн т к 2030; доставка 15–20
дней вместо 35–45 через Суэц. Порт Махачкала: 3,5 млн т в 2025,
янв–авг 2026 — 2,9 млн т (+42,5%), мощность ~10–11 млн т к 2030.
Источники: РЖД / Правительство РФ, Росморречфлот, АСОП (окт 2026).

## Паромы (default, публичные данные)

Фиксированного расписания у каспийских паромов нет: рейс
Баку–Туркменбаши ~17 ч, Курык–Баку <24 ч, ожидание 1–2 дня —
норма, до недели при заторах (Wikivoyage, GetTransport 2026).
В модели: средний интервал 72 ч, пропуск рейса +48 ч.

## CO₂ и стоимость (default)

CO₂ — DESNZ 2026, well-to-wheel: ж/д 33, паром RoRo 63, фура 97
г/т-км. Метод: ISO 14083 / GLEC v3.2, разбивка по транспортным
элементам цепи (TCE) на каждое плечо. Хабовые операции не учтены —
нет первичных данных (сказано честно в ответе API).
Ставки моря — Argus Caspian Transport, окт 2025: Актау–иранские
порты $40–45/т, Астрахань–иранские порты $63–65/т.

## Демо (demo — иллюстративный снимок, не live)

- Загруженность портов (%), очереди на таможне (ч).
- Список грузов SHP-1042/1043/1044 и их документы.
- Сценарий шторма (ветер 19 м/с, волна 3,4 м — экстремум, за 90
  дней максимум волны 2,52 м).

## Что отсутствует (нет открытого источника)

- Живые данные портов (загруженность, расписание паромов).
- История реальных задержек рейсов (поэтому ML-метки — по правилам).
- GPS/AIS-трекинг судов и вагонов.
- API таможни для pre-clearance.

Для пилота эти данные берутся у порта и таможни напрямую —
см. ROADMAP.md.
