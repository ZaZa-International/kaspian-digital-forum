# Файлы для демонстрации SHP-1042

Все файлы синтетические. Они нужны для проверки извлечения полей,
расхождений и актуальности квитанции. Юридической силы у них нет.

В пульте выберите SHP-1042 и вкладку «Документы». Перед каждой загрузкой
выберите соответствующий вид документа.

| Файл | Вид в интерфейсе | Ожидаемый результат |
|---|---|---|
| `01-invoice-wrong.txt` | Счёт-фактура | Расхождение: 60 т вместо 48 т |
| `02-invoice-correct.txt` | Счёт-фактура | Совпадение с 48 т; заменяет предыдущую оценку счёта |
| `03-packing-list.txt` | Упаковочный лист | Поля совпадают |
| `04-certificate-of-origin.txt` | Сертификат происхождения | Поля совпадают |
| `05-insurance.txt` | Страховой полис | Поля совпадают |
| `06-bill-of-lading.txt` | Морская накладная | Поля совпадают |
| `07-rail-waybill.txt` | Железнодорожная накладная | Поля совпадают |

Для короткой демонстрации достаточно первых двух файлов: загрузить ошибочный,
подписать оценку, проверить изменённую копию, загрузить исправленный
и показать неактуальность первой квитанции. Оставшиеся файлы позволяют
заполнить весь чек-лист исходного маршрута. Совпадение извлечённых полей
не подтверждает подлинность файла или разрешение таможни.
